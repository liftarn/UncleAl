# Uncle Al's Gate - Rhythmic Noise Gate & Squelcher (JUCE VST3/AU)

An audio effect plugin inspired by the industrial sound of Ministry. Features an aggressive downward expander, tempo-synced 16-step chopper, and a unique "Dirt" sidechain filter that injects white noise, vinyl crackle, or radio static strictly when the gate opens.

---

## Features
- **Gate Dynamics**: Sub-millisecond attack (0.05ms) and fast release (1ms) for brutal, machine-gun gating.
- **Hard Squelch**: Instantly snaps signals below threshold to absolute silence.
- **Rhythmic Chopper**: Locks gate pulses to DAW host tempo (1/4 to 1/64) with 16-step sequencer and swing.
- **Dirt Blender**: Injects vinyl dust, white/pink noise, transformer hum, or radio static modulated by the gate envelope.
- **Sidechain Filter**: Bandpass / Highpass / Lowpass with Audition mode to target snare crack or guitar transients.
- **Brickwall Limiter**: Output stage protection for high-impact industrial mixes.
